`x-show` — одна из самых полезных и мощных директив Alpine. Она обеспечивает выразительный способ отображения и скрытия элементов DOM.

Вот пример простого раскрывающегося компонента с использованием `x-show`:

```html live
<div x-data="{ open: false }">
  <button x-on:click="open = !open">Переключить раскрывающийся список</button>

  <div x-show="open">Содержимое списка...</div>
</div>
```

При нажатии кнопки раскрывающийся список будет отображаться и скрываться соответственно.

:::tip
    Если состояние `x-show` при загрузке страницы равно «false», вы можете использовать на странице директиву [`x-cloak`](/directives/cloak), чтобы избежать «мерцания страницы» (эффект, который возникает, когда браузер отображает ваше содержимое до того, как Alpine завершит его инициализацию и скрытие).
:::

## С переходами

Если вы хотите применить плавные переходы к поведению `x-show`, попробуйте использовать её вместе с [`x-transition`](/directives/transition). Вот краткий пример того же компонента, что и выше, только с применёнными переходами:

```html live
<div x-data="{ open: false }">
  <button x-on:click="open = !open">Переключить раскрывающийся список</button>

  <div x-show="open" x-transition>Содержимое списка...</div>
</div>
```

## `.important`

Иногда вам нужно приложить немного больше усилий, чтобы действительно скрыть элемент. В тех случаях, когда селектор CSS применяет свойство `display` с флагом `!important`, оно будет иметь приоритет над встроенным стилем, установленным Alpine.

В этих случаях вы можете использовать модификатор `.important` для установки встроенного стиля `display: none !important`.

```html ".important"
<div x-data="{ open: false }">
  <button x-on:click="open = !open">Переключить раскрывающийся список</button>

  <div x-show.important="open">Содержимое списка...</div>
</div>
```

Что делает `x-show` с элементом?

```html wrap
<div x-show="false">...</div>
```

- [ ] Полностью скрывает его из разметки HTML
  > Элемент остаётся в DOM — `x-show` не удаляет его из разметки.
- [x] Добавляет атрибут `style="display: none"`
  > При ложном значении Alpine скрывает элемент инлайновым стилем `display: none`.
- [ ] Прячет элемент между тегами комментариев
  > Комментарии здесь не используются — это приём других библиотек, а не `x-show`.
